# おみくじアプリ（GitHub × AI 初心者向け研修デモ）

GitHub と生成 AI（ChatGPT・Codex）を使ったアプリ開発の流れを体験するための研修用リポジトリです。
ビルド不要の静的なおみくじアプリを教材にしています。

## アプリの概要

- 「おみくじを引く」ボタンを押すと、約 0.8 秒の演出後に「大吉」「中吉」「小吉」のいずれかを色分けして表示します。抽選確率はそれぞれ 3 分の 1 です。
- 結果と一緒に、総合コメント、仕事運、金運、恋愛運、ラッキーアイテム、カラー、数字を表示します。
- 各運勢に 2 組の候補があり、「もう一度引く」で選び直します。同じ内容が続く場合もあります。
- 抽選前は詳細情報を表示せず、演出中はボタンを無効にして重複した抽選を防ぎます。
- OS やブラウザで「動きを減らす」設定を有効にしている場合は、演出を省略して結果を表示します。
- HTML、CSS、JavaScript の 3 ファイルだけで動作し、外部 API やデータベースは使用しません。
- スマートフォンの画面サイズにも対応しています。

## ファイル構成

- `index.html`：画面の見出し、結果表示欄、ボタンなどの骨組みを定義するファイル
- `style.css`：文字の大きさ、余白、色などの見た目を整えるファイル
- `script.js`：運勢ごとの候補データ（`FORTUNE_DATA`）、抽選処理、演出と表示切り替えを管理するファイル
- `README.md`：リポジトリの概要、実行方法、基本用語をまとめた説明書

## 実行方法

特別なインストールやビルドは不要です。

1. リポジトリを手元にダウンロード（またはクローン）します。
2. フォルダ内の `index.html` を、ブラウザ（Chrome、Edge、Safari など）で直接開きます。
3. 「おみくじを引く」ボタンを押して、演出後に結果と補足情報が表示されることを確認します。
4. 「もう一度引く」で再抽選します。

GitHub Pages でも、同じ HTML、CSS、JavaScript をそのまま静的ページとして配信できます。

## 研修で使用する基本用語

- **リポジトリ**：アプリのファイルと変更履歴をまとめて管理するプロジェクトの箱
- **Issue**：追加したい機能や直したい点（やりたいこと・課題）を記録する機能
- **ブランチ**：元の状態（`main`）を保ったまま、別の作業場所を分けて修正する仕組み
- **コミット**：ファイルの変更内容を履歴として記録すること
- **Push**：手元（または作業環境）で記録した変更を GitHub へ送ること
- **Pull Request（PR）**：ブランチで行った変更の差分を見せ、本流への取り込みを提案・確認する機能
- **Merge**：Pull Request で確認した変更を `main` ブランチへ統合すること
